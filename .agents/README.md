# Agent Automation and Plans

Welcome to the central hub for AI automation within the **Lumini Estética** project, authored by **Vitória Rodrigues Ferreira**.

This directory contains the core rules, custom skills, and execution plans that empower our AI agents to operate autonomously while adhering to strict architectural and business guidelines.

## Structure

- [skills](./skills/): Defines custom AI behaviors and required competencies.
- [plans](./plans/): Houses detailed execution plans and project milestones to track development objectives.

## Planning

The `plans/` directory is designated for outlining development objectives, system requirements, and architectural milestones. All agents and contributors must refer to the global guidelines defined in [README.md](../README.md) to ensure consistency across the monorepo.
